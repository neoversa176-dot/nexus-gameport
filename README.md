# GameVault Marketplace

Build a complete, production-quality responsive gaming marketplace website called GameVault. Create fully original branding, UI, copy, abstract geometric icon/logo, and placeholder imagery; do not copy any competitor’s layout, logo, graphics, or text. Use a premium dark gaming/SaaS aesthetic: #0B0D12/#10131A backgrounds, #151923 cards, #1B2030 elevated cards, electric purple/indigo primary, cyan secondary, subtle gradients, glass borders, rounded surfaces, hover motion and tasteful glow.

Deliver a polished functional front-end prototype with working navigation and realistic interactive states. Include:
- Sticky desktop/mobile header: logo, Browse, Games, Sell, How It Works, Support; search, language/currency, sign-in/create account; authenticated UI affordances such as avatar, notifications, messages, wallet, dashboard menu.
- Homepage hero with headline “Everything You Need to Level Up”, marketplace subtitle, large autocomplete-style search with suggested popular/trending/recent searches, and an original abstract gaming visual background (no copyrighted artwork).
- Horizontally scrollable Popular Games section with original illustrative/icon placeholders and listings count for Roblox, Fortnite, Valorant, League of Legends, Minecraft, Old School RuneScape, Counter-Strike 2, Call of Duty, Grand Theft Auto V, World of Warcraft, Path of Exile, Rocket League, Rainbow Six Siege, Pokémon, Brawl Stars.
- Marketplace category cards for Accounts, Currency, Items, Boosting, Top Ups, Gift Cards with distinct icons/descriptions/CTAs.
- A marketplace browse/search results view accessible from navigation/search: adaptive left filters (game, category, price, seller rating, delivery, region/platform/server/level/rank/rarity plus instant delivery/verified), result count, sorting, grid/list switch, product cards.
- Premium product cards including image, game, title/category, seller avatar/name/verification/rating/reviews, delivery, price/discount, instant badge and favorite interaction.
- Product detail view opened by product cards: gallery with preview images/video-style frame, listing and seller info, quantity, Buy Now/Add to Cart/favorite interactions, product description/included attributes/delivery, strong Buyer Protection card, reviews/rating distribution, similar products.
- Make buttons, search suggestions, filters, sort, favorites, grid/list, navigation, and product selection visibly interactive using local state and mock data. Include cart/wallet/dashboard affordances in a coherent way.

Aim for a visually exceptional landing experience first, then build the browse and product detail views so the end-to-end marketplace concept feels complete. Ensure desktop and mobile responsiveness, accessible contrast, original UI, and no empty dead-end controls.
